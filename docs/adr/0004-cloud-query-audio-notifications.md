# 用官方语音会话查询并播报完成通知

官方云端只允许在 detect 中传唤醒词，实机把查询句放进去已被拒绝；用户希望保留原 Muse UI、官方语音服务及后续结果查询。因此用独立认证通知通道告知设备，再通过按键式 manual 会话上行离线生成的固定 Opus 查询句，由专用 MCP 工具领取准确任务批次，结果语音仍由官方云端生成；不下载外部 OGG，也不靠扬声器喊话。

用户确认成功、失败和超时都告知，忙时等待，通知保留24小时，积压合并，播完回待机。待听并非一定有人在说话：无云端回答待处理且连续安静15秒时可让出会话，有声音或正在播放仍等待。收到信号、发出查询都不足以清队列；须有该批次查询回执和设备音频排空回执，失败则保留重试。新结束的任务留到下一批。普通固件OTA会覆盖这一适配，升级应继续使用原UI基线。
