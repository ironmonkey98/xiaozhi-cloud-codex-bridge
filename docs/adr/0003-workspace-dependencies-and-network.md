# 可写工作区自动安装项目依赖并联网

真实 PPT 任务 T-10 只生成了脚本：缺少 `python-pptx`，旧权限又禁止安装库和联网，导致用户拿不到请求的 PPT。用户已明确授权扩大工作区内自动执行能力，因此可写项目允许项目依赖安装、联网下载、资料搜索和程序执行，无逐次确认；只读项目保持原授权。

保留 `workspace-write` 文件边界和 `approvalPolicy: 'never'`，而不是移除整机沙箱。Node 包、Python 虚拟环境、缓存和临时文件均放在工作区，系统软件安装、sudo、提交推送与外部发送不在本次工作区授权内；继承的外部 MCP 工具保持关闭。任务默认超时提高到十分钟，给安装库和生成文档留出时间。提示与 MCP 说明明确要求生成真实 PPT/Word/Excel/PDF 文件，缺库时在工作区自行安装。

本决定取代 ADR 0002 中“可写项目禁止联网与依赖安装”的部分，其他文件边界继续有效。网络对可写项目开放，不是仅包仓库白名单；两种模式仍没有读取隔离，依赖安装也可能运行包的安装脚本。用户的授权范围是工作区自动执行，不是整机完全权限。
