# 语音直接写入专用工作区，不弹窗审批

联网与项目依赖安装的限制已由 [ADR 0003](0003-workspace-dependencies-and-network.md) 调整；本文记录初始决策。

用户希望通过小智语音直接创建和运行程序；逐次在 Mac 上审批会打断语音使用。我们保留工程项目只读，并由本机配置单独登记专用可写项目（`desk`，桌面工作区），使用 `workspace-write` 沙箱和 `approvalPolicy: 'never'`；小智只能选择项目别名，不能调整授权。此决定是对 V1.1 只读基线的已授权扩展。

写入只授权所选项目文件夹，清空附加可写根目录、排除 `/tmp` 与 `$TMPDIR`，并禁用继承的 MCP 工具；网络与 Web 搜索始终关闭。安装软件、提交推送和外部路径请求在 Gateway 先行拒绝，关键词与提示词只用于减少误操作，写入硬边界由 Codex 沙箱提供。`.git` 等受保护目录不在授权内。

代价是可写项目内的误删和程序执行不再逐次确认；取消任务也不会回滚已完成的文件操作。两种模式都不提供工作区外的读取隔离，文件内容仍可能经模型处理和小智播报离开本机；需要读取隔离时必须采用专用低权限账号或操作系统级隔离环境。我们没有选择把整个桌面或家目录设为可写，也没有增加 `danger-full-access` 模式。
